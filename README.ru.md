# formatted

[English version](./README.md)

Локальный тренажёр модуля баз данных демонстрационного экзамена. Разбираешься в данных, самостоятельно нормализуешь их в LibreOffice Calc, затем создаёшь таблицы PostgreSQL и пишешь SQL в pgAdmin.

## Что работает

| Раздел       | Что тренируем                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| Блиц         | 44 вопроса, из них 25 по ИНДЕКС и ПОИСКПОЗ: смысл, выбор подхода, вычисление результата и поиск ошибок             |
| Генератор    | Три связанных CSV для нормализации в 12 таблиц; торговля, библиотека или учебный центр; меняющиеся условия выборок |
| Своя AI-тема | Вводишь тему, проверяешь предложенные Qwen описание и названия, применяешь к выбранной модели данных               |
| На время     | Таймер с сохранением срока завершения, проверка трёх числовых ответов и чек-лист нормализации                      |
| Проверка таблиц | Загрузка 12 CSV и schema.json; проверка PK/FK, дублей, связей и сохранности исходных данных                     |
| Рабочая книга Calc | Одна книга на семь шагов, проверка формул и итоговых CSV                                                    |
| Прогресс     | Локальная история и достижения, без аккаунта и облачной синхронизации                                              |

Из `formuly.docx` изучаем только **ИНДЕКС + ПОИСКПОЗ** с точным поиском. Удаление дубликатов, «Текст по столбцам» и экспорт CSV являются отдельными операциями Calc.

## Запуск

Установи Node.js 22.12+ и Git. В папке склонированного репозитория:

```sh
npm ci
npm start
```

Тренажёр рассчитан на macOS и Windows; проверки desktop сейчас выполняются на macOS. Запуск на Windows ещё нужно проверить. Для самой разработки WinForms нужны Windows и визуальный конструктор Visual Studio; обработчики пишутся на C#.

Можно использовать `Start.command` на macOS или `Start.cmd` на Windows: они проверяют Node и устанавливают недостающие зависимости проекта. В «Обзоре» есть проверка окружения и ссылки на официальные установщики. Системные программы приложение само не устанавливает. Проверка из терминала: `npm run doctor`.

## Разбор CSV в Calc

Раздел «Разбор CSV в Calc» содержит семь шагов на одном небольшом вымышленном CSV: импорт, очистка, удаление повторов, ПОИСКПОЗ, ИНДЕКС, вставка значений и экспорт. На каждом шаге есть пример и вопрос. Мини-урок выделяет справочник категорий, а не полную схему из 12 таблиц.

«Открыть мою книгу» использует Python 3.9+ и LibreOffice. Работа сохраняется между шагами в `calc-lessons/work/lesson.fods` внутри профиля приложения. Можно сохранить как `lesson.ods` в той же папке. Импортируй исходник на лист «Практика», выполни шаг, сохрани книгу и нажми «Проверить этот шаг». Проверяются ведущие нули, неизменность исходника, справочник, формулы, вставка чисел и итоговые `products.csv` / `categories.csv` (UTF-8, разделитель `;`). ИНДЕКС и ПОИСКПОЗ с обычными ссылками вычисляются независимо от сохранённых результатов; именованные диапазоны и другие функции в урок не входят.

Демонстрационные примеры остаются отдельными копиями. Скрипт использует отдельный профиль Calc и не перезаписывает существующую работу. Без Python/Calc доступны урок в приложении и скачивание CSV. Во время попытки на время подсказки закрыты.

## Бесплатная локальная AI

1. Установи и открой [Ollama](https://ollama.com/download)
2. В генераторе открой раздел AI, разверни инструкцию и нажми «Скачать модель»
3. Подтверди скачивание, введи вымышленную тему и проверь полученный черновик

Используется [Qwen3 4B Instruct](https://ollama.com/library/qwen3:4b-instruct): около 2,5 ГБ на диске и дополнительная оперативная память для работы. Интернет нужен для установки и скачивания. Дальше генерация локальная: без API-ключа, аккаунта, платного сервиса и настройки адреса. Модель не встроена в приложение, первая установка необходима.

AI меняет названия и описание **внутри одной из трёх готовых моделей**, сохраняя 3 CSV и 12 таблиц. Черновик можно исправить перед применением; исправления тоже проходят проверку. Связи, ID, строки и числовые ответы формирует приложение. Исходные скриншоты WinForms не меняются. Текст задания содержит порядок работы, состав результата и критерии проверки первого модуля, не полный официальный комплект экзамена.

Desktop-процесс обращается только к `127.0.0.1:11434`, без учётных данных и перенаправлений. В промпт попадают введённая тема и вымышленный словарь, но не файлы пользователя или история занятий. Не вводи персональные данные. Модели и секреты не храним в Git. Подробнее о локальной обработке: [FAQ Ollama](https://docs.ollama.com/faq).

## Файлы и повторение варианта

Экспорт сохраняет **три CSV, `assignment.md` и `variant.json`**, без готовой схемы и SQL. Исходники разбиваешь сам и отдельно экспортируешь свои 12 таблиц. Чтобы повторить AI-вариант, сохрани и импортируй `variant.json`: одного кода недостаточно для восстановления темы. Импортированная тема работает без Ollama.

Сохраняем формат «3 CSV и 12 таблиц», не копируя количество Excel-файлов из примера. Двенадцать таблиц является целью этих упражнений, а не общим правилом нормализации. Старые однофайловые варианты продолжают открываться.

В генераторе и после попытки доступна «Проверка своих таблиц»: загрузи 12 CSV и `schema.json`. В описании укажи назначение каждой таблицы, файл, PK, соответствие столбцов исходнику и связи FK; пример есть рядом с загрузкой. Можно использовать свои ID, названия и порядок строк. Проверяются 12 учебных сущностей, не все возможные декомпозиции и не ограничения реальной PostgreSQL. Файлы остаются на устройстве; проверка после попытки служит разбору, а не подтверждению сдачи до таймера.

## Разработка

Строгий TypeScript, Electron и [Google gts](https://github.com/google/gts). Отступ 2 пробела, одинарные кавычки, точки с запятой, короткие комментарии по делу.

Отдельный [табличный движок](./src/spreadsheet/README.md) подключён к **«Разбор CSV в Calc» → «Открыть редактор таблиц»**: отдельное окно, сетка 100×12, строка формул, отмена изменений и RU/EN. Кнопка **ƒx** открывает отдельный мастер: поиск ИНДЕКС/ПОИСКПОЗ, аргументы и предварительный результат. Учебная книга хранится только в памяти, пока без импорта и сохранения файлов. Существующий разбор в настоящем Calc по-прежнему требует LibreOffice.

| Команда                | Назначение                                       |
| ---------------------- | ------------------------------------------------ |
| `npm run check`        | Типы, стиль и тесты логики                       |
| `npm run test:engine`  | Тесты табличного движка                          |
| `npm run test:sheets`  | Сценарии редактора и скриншоты размеров окна      |
| `npm run bench:engine` | Локальный замер скорости движка                  |
| `npm run test:desktop` | Проверка сценариев в отдельном тестовом профиле  |
| `npm run preview`      | Браузерное превью; AI доступна только в desktop  |
| `npm run fix`          | Исправление стиля кода                           |
| `npm run package`      | Неподписанная сборка для текущей ОС в `release/` |

`src/core/` содержит логику упражнений, `src/app.ts` интерфейс, `electron/` экспорт и подключение локальной модели. Сгенерированные файлы `build/` не редактируем и не коммитим. Тесты подключения AI используют подставные ответы и не скачивают модель.

Пока нет исполнения и проверки SQL, модулей 2–4, автоматической установки системных программ и блокировки других приложений. Проверка запуска на настоящей Windows ещё нужна, локальные тесты её не заменяют. Основа: `formuly.docx`, приложенные материалы экзамена 2027 года и [пример ShoeStore преподавателя](https://github.com/KesinWeb/ShoeStore).
